BÂTI JL — SITE VITRINE
======================

Contenu
-------
- index.html : accueil
- prestations.html : prestations
- realisations.html : galerie illustrative
- contact.html : contact et appels téléphoniques
- mentions-legales.html : modèle à compléter
- styles.css : design anthracite et doré, responsive
- script.js : menu mobile et année automatique

AVANT PUBLICATION
-----------------
1. Vérifiez toutes les informations et les prestations proposées.
2. Remplacez les images illustratives par des photos de vos propres chantiers si possible.
3. Complétez entièrement mentions-legales.html : nom légal, statut, adresse professionnelle, SIRET, e-mail, hébergeur, etc.
4. Vérifiez vos assurances et les mentions obligatoires applicables à votre activité.
5. Les photos sont chargées depuis Unsplash et nécessitent une connexion Internet. Vérifiez leurs conditions d'utilisation avant diffusion.
6. Le site ne comporte pas de formulaire qui envoie des messages : les visiteurs peuvent vous appeler ou ouvrir WhatsApp.

PUBLIER GRATUITEMENT AVEC GITHUB PAGES
--------------------------------------
Option recommandée pour héberger ces fichiers statiques gratuitement :

A. Préparez un compte sur https://github.com/
B. Créez un nouveau dépôt public, par exemple bati-jl-site.
C. Téléversez tous les fichiers et dossiers du ZIP à la racine du dépôt (pas le ZIP lui-même).
D. Dans le dépôt, ouvrez Settings > Pages.
E. Dans Build and deployment, choisissez Deploy from a branch.
F. Choisissez la branche main et le dossier / (root), puis cliquez Save.
G. Attendez la fin du déploiement. GitHub affichera l'adresse publique du site dans Settings > Pages.

L'adresse sera généralement du type :
https://VOTRE-NOM.github.io/bati-jl-site/

Vous pouvez ensuite modifier les fichiers sur GitHub et les changements seront publiés après le déploiement.

IMPORTANT
---------
- Les images de ce site sont des images d'illustration et ne doivent pas être présentées comme des chantiers réels de BÂTI JL.
- Le texte « rayon indicatif de 20 km » est indicatif : confirmez les communes où vous intervenez.
- Le fichier mentions-legales.html est un modèle incomplet. Complétez-le avant de rendre le site public.
- GitHub Pages héberge les fichiers, mais n'offre pas de boîte mail professionnelle ni de formulaire de contact avec envoi de message.
